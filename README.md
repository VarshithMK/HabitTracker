# DAILY — Habit Tracker

A responsive personal habit tracker with a minimal dark interface.

## Features
- Create, edit, and delete habits
- Daily completion checklist and score
- Current and best streaks
- Weekly consistency chart and recent history
- Local browser storage — no account or backend required

## Run locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml` that deploys the root folder to GitHub Pages on pushes to `main`.

In GitHub, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. After the first successful workflow run, your Pages URL will appear in that section.
